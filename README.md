# Actividad GitHub Pages

## Descripción del proyecto

Este repositorio se ha creado para realizar una actividad del módulo relacionada con GitHub y GitHub Pages.

El objetivo de la actividad es crear una rama específica llamada `gh-pages`, preparar su contenido y utilizarla para publicar una página mediante GitHub Pages.

## Tecnologías utilizadas

- Git
- GitHub
- GitHub Pages
- Markdown
